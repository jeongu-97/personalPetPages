
# PersonalPetPage

개인 펫 프로필 페이지 프로젝트입니다.

## Running

Run `npm i` to install dependencies.

Run `npm run dev` to start Vite frontend dev server.

## Local Modes

Use `npm run dev` when you only need UI development.

Use `npx vercel dev` when you need to test `/api/pet` together with frontend.

Do not run `npm run dev` and `npx vercel dev` at the same time on the same port.
